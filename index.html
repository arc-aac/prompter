블루투스 리모컨 설정

기기의 블루투스 설정에서 리모컨을 먼저 연결하세요. 아래 기능의 등록 버튼을 누른 다음 리모컨 버튼을 한 번 누르면 저장됩니다.

리모컨 버튼을 누르면 여기에서 수신한 키를 확인할 수 있습니다.

기본 키: Space/Enter = 재생·정지, ↑/↓ 또는 Page Up/Down = 페이지 이동, ←/→ 또는 −/+ = 속도 조절, Home = 처음, Escape = 종료.

키가 표시되지 않으면 기기가 신호를 웹앱에 전달하지 않는 상태입니다. 리모컨의 키보드 모드가 있다면 전환해 보세요. 휴대폰 홈·전원·볼륨 버튼과 미디어 버튼은 기기와 브라우저에 따라 사용할 수 없습니다.
